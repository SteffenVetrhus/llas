# Spanish from Scratch: The 10-Week Mission

A modern, psychologically-optimized language learning platform built with React Router v7 and Tailwind CSS. This app implements research-backed pedagogical approaches to help learners reach A1 Spanish proficiency in 10 weeks.

## Features

### Pedagogical Approach

- **Task-Based Language Learning (TBLL)**: Each week is a real-world mission
- **Comprehensible Input**: Learn by understanding messages, not memorizing rules
- **Active Recall & Spaced Repetition**: Scenario-based quizzes that build lasting memories
- **Contextual Grammar**: Grammar as a tool to complete your mission

### Psychological Engagement

- **Streak Tracking**: Daily learning streaks with visual feedback
- **XP System**: Earn experience points for completing modules and quizzes
- **Achievement System**: Unlock badges for milestones
- **Progress Visualization**: Beautiful progress bars and completion tracking
- **Gamification**: Level system based on XP earned
- **Micro-animations**: Smooth transitions and interactive elements

### Module Types

1. **Dialogue (Comprehensible Input)**: Interactive conversations with audio playback
2. **Vocabulary Builder**: Flashcards with audio and mastery tracking
3. **Grammar Tools**: Contextual grammar explanations with examples
4. **Culture Bytes**: Cultural insights and context
5. **Speech Lab**: Practice pronunciation with recording simulation
6. **Quizzes**: Multiple question types (fill-in-blank, multiple choice, scenario)

## Tech Stack

- **React 18**: Modern React with hooks
- **React Router v7**: Client-side routing
- **Tailwind CSS**: Utility-first styling
- **Framer Motion**: Smooth animations and transitions
- **Lucide React**: Beautiful icon library
- **LocalStorage**: Persistent progress tracking
- **Web Speech API**: Text-to-speech for pronunciation

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Course Structure

### 10 Weeks of Learning

1. **Week 1: First Contact** - Introductions and greetings (FULLY IMPLEMENTED)
2. **Week 2: Mapping Your World** - Location and household vocabulary
3. **Week 3: The Daily Routine** - Present tense and reflexive verbs
4. **Week 4: The Café** - Food ordering and numbers
5. **Week 5: Making Plans** - Future expressions and time
6. **Week 6: Likes & Dislikes** - Gustar and preferences
7. **Week 7: The Super Verbs** - Stem-changing verbs
8. **Week 8: What's Happening?** - Present progressive
9. **Week 9: A Trip to the Market** - Simple past tense
10. **Week 10: The Story** - Storytelling and irregular preterites

## Psychological Design Elements

### Retention Strategies
- Visual feedback on every action
- Celebration animations on completion
- Progress bars everywhere
- Immediate rewards (XP)

### Motivation Boosters
- Streak tracking creates habit formation
- Achievement system provides goals
- Level progression shows growth
- Beautiful UI reduces friction

### Learning Optimization
- Spaced repetition in vocabulary
- Active recall in quizzes
- Comprehensible input first
- Context before grammar
